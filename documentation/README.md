# SonicSentinel AI Documentation

This folder contains the project documentation and visual showcase package.

## ⚠️ Read this before submitting

Four items in this package are **generated rather than measured**, and one of them is a reporting
problem rather than a defect. Fix these before submission.

| # | What | Where | Fix |
|---|------|-------|-----|
| 1 | **15 evaluation graphs are fabricated** — confusion matrices from a closed-form formula plus `np.random.choice`, accuracy figures from literals, all captioned *(Test Set)* | `graphs/`, `build_diagrams_and_graphs.py` | Measure, or delete |
| 2 | **Prediction log is synthetic** — different files carry byte-identical probability vectors, every true label is `Unknown` | `model-evidence/raw_prediction_debug.csv` | Delete, or regenerate from a real run |
| 3 | **SRS matrix is generated by a loop** — 99 requirements, 96 auto-stamped `IMPLEMENTED` with the same evidence string | `SRS_COMPLIANCE_MATRIX.md`, `build_markdown_files.py:20–51` | Write from the SRS, or delete |
| 4 | **Admin password published in plaintext** | root `README.md`, `ml-service/.env:26–28` | Remove and rotate |

**On item 1.** The confusion-matrix diagonal is computed as `0.93 − idx × 0.015` and every
off-diagonal cell is a seeded random draw, so the pattern of which classes the model confuses is
an artefact of `np.random.seed(42)`. These are not measurements, and the two ways to fix them are
both acceptable:

- **Measure** — run each ensemble member over a named held-out split and write the matrices from
  the returned arrays. The ensemble already returns per-class probabilities, so this is a few
  hours, and it produces defensible evidence.
- **Remove** — delete the graphs and the prediction log, and state plainly in the report that
  model performance was not benchmarked in this submission.

Do not leave generated graphs in place on the assumption nobody will check the code.

**On item 3.** The suite referenced in the auto-stamped evidence string exercises twelve
scenarios. It cannot verify ninety-six requirements.

Full citations for all four: [`VERIFICATION_REPORT.md`](./VERIFICATION_REPORT.md) finding **D-4**.

## Open gap — dataset provenance

There is currently **no dataset provenance record**. No download script, no source manifest,
no licence file, and no training corpus exists in this repository, and no file anywhere
mentions Freesound, Pixabay, ElevenLabs, Urban8k, or ESC-50.

To close the gap from evidence rather than assertion:

```bash
python ml-service/tools/dataset_provenance.py --root "C:/path/to/actual/corpus" \
  --out documentation/dataset/evidence
```

Then complete the blank source, licence, synthesis, ethics, and split tables in the generated
`provenance.md` from your actual download history. See finding **D-2** in the verification
report.
